# Sprint_5

Автотесты для сайта Stellar Burgers.

## Что это

Это мой учебный проект с автотестами. Я написал тесты на Python с использованием Selenium для проверки сайта Stellar Burgers.

## Что внутри

- `tests/` - папка с тестами
- `locators.py` - тут все локаторы элементов
- `helpers.py` - функции для генерации email и пароля
- `conftest.py` - настройки для pytest
- `requirements.txt` - библиотеки которые нужны

## Что проверяют тесты

**Регистрация:**
- Регистрация с правильными данными
- Ошибка когда пароль меньше 6 символов

**Вход:**
- Вход через кнопку "Войти в аккаунт"
- Вход через "Личный кабинет"
- Вход через форму регистрации
- Вход через форму восстановления пароля

**Личный кабинет:**
- Переход в личный кабинет
- Переход обратно в конструктор
- Выход из аккаунта

**Конструктор:**
- Клик по вкладке "Булки"
- Клик по вкладке "Соусы"
- Клик по вкладке "Начинки"

## Как запустить

1. Установить зависимости:
```
pip install -r requirements.txt
```

2. Запустить все тесты:
```
pytest tests/
```

3. Запустить один файл:
```
pytest tests/test_login.py
```

## Важное

- Тесты сами создают email и пароль для каждого запуска
- Email создается так: dmitriy_zyabikov_46_XXX@yandex.ru (где XXX это случайные цифры)
