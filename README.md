# Sprint_5

Автотесты для сайта Stellar Burgers.

## Описание проекта

Учебный проект для написания автотестов на Python с использованием Selenium.

## Требования

- Python 3.x
- Selenium
- Pytest

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest tests/
```
